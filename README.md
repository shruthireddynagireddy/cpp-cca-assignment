# C++ CCA Assignment

100 C++ programs: 20 each on Arrays, Enum, Structure, Pointers and Union.

| Folder | Topic |
|--------|-------|
| `01_Arrays` | 1D/2D arrays, searching, sorting, matrices |
| `02_Enum` | enum, enum class, bit flags, state machines |
| `03_Structure` | structs, nested structs, arrays of structs, pointers to structs |
| `04_Pointers` | pointer basics, arithmetic, dynamic memory, function pointers, smart pointers |
| `05_Union` | unions, tagged unions, endianness, bit patterns |

## Compile and run
```bash
g++ -std=c++17 01_Arrays/01_input_and_display.cpp -o out
./out        # on Windows: out.exe
```
